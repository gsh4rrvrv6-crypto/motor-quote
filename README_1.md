# Motor Quote Comparison

A Streamlit app for comparing Australian motor insurance quotes side by side.

## Features

- Enter vehicle details, driver info, parking and usage
- Add quotes from multiple insurers (GIO, AAMI, NRMA, Youi, Budget Direct, and more)
- Compare all quotes side by side with a clear best-value highlight
- Download comparison as a CSV
- Pre-loaded with common Australian insurer names

## How to deploy

1. Upload these files to a GitHub repository
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Click "New app" and connect your GitHub repo
4. Set the main file path to `app.py`
5. Click Deploy

## Local development (optional)

```bash
pip install -r requirements.txt
streamlit run app.py
```
